# Zi / 梓

The independent Zi product family website. The site is static and bilingual:

- `/` — English
- `/zh.html` — 简体中文
- `/zispace.html` and `/zispace-zh.html` — ZiSpace product page

ZiSpace is in local development. ZIsland and Zilan product visuals are labeled as concepts where appropriate. The demo video is an original project asset and is not a release content library.

Preview locally with `python3 -m http.server 8080` from this directory.

The public deployment target is `zi.fuluoyide.top`. Source files for app installation and internal review are intentionally excluded.

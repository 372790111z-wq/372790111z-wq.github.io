## 目标与范围

在现有 fuluoyide.top 主站内容栏目新增「作品集」，收录纸间网站；扩展现有「关于我」，提供新版个人网站入口。保留主站首屏、现有案例、Skills、写作和交流。默认栏目仍为案例；预览默认展示作品集仅方便审阅。
不改根域名与 www 的绑定或跳转，不迁移两个子站，不修改其他项目，不改变 GitHub 仓库权限。

## 功能一：作品集栏目与纸间入口

1. 业务目的：让访客从主站发现个人搭建的网站项目。
2. 使用者：所有主站访客，无登录或权限要求。
3. 触发：主站现有栏目条，Skills 后、写作前新增「作品集」。纸间入口标识为 `portfolio-zijian-link`。
4. 流程：点击作品集切换对应面板，展示纸间项目卡；点击卡片在新标签打开 https://zijian.fuluoyide.top/ ，原主站保留当前栏目。
5. 规则：栏目顺序为案例、Skills、作品集、写作、关于我、交流；纸间只出现一次。标题「纸间 · 视觉创作工具库」，说明为「我搭建的视觉 Skill 样张库。按风格浏览作者示例，找到合适的创作工具。」
6. 边界：只收录已上线的纸间网站；不把其中第三方作者样张当作个人作品。无后台、搜索或动态收录。外部站点不可达时由浏览器呈现错误，主站仍可返回；不显示虚假加载成功状态。
7. 数据：固定名称、说明、URL 和标识；选中栏目沿用现有状态机制。无新接口或持久化数据。
8. 验收：新增栏目可切换；现有栏目可用；纸间链接可实际打开正确站点；新窗口链接含 noopener/noreferrer；390px 手机可操作，无页面横向溢出；栏目条允许横向滚动。

## 功能二：扩展现有关于我

1. 业务目的：让访客进入完整的个人经历与实践介绍。
2. 使用者：所有主站访客，无登录或权限要求。
3. 触发：现有「关于我」栏目；完整个人站链接标识为 `about-personal-site-link`。
4. 流程：点击关于我显示介绍面板；点击「查看完整个人网站 ↗」在新标签打开 https://portfolio.fuluoyide.top/ ，原主站保留。
5. 规则：不新增第二个关于我栏目。面板标题「张梓琪 / AI 产品与个人实践。」；说明「从产品经历到个人项目，了解我正在做的事情。」；与已确认预览一致。
6. 边界：不在主站嵌入 iframe 或复制整站；不改新版个人网站内容、域名或默认 Vercel 地址。外部站点失败不影响主站入口。
7. 数据：固定介绍文字、URL 和标识；无接口与账号数据。
8. 验收：只有一个关于我栏目；实际链接到新版网站；新标签安全属性有效；390px 和桌面布局正常；主站其他功能保留。

## 实施约束与验证

进入生产代码前定位主站当前版本的可维护源码，确认仓库、分支及未提交变更；main 当前所见为构建产物，master 是不同旧版，不能混用或直接替换旧站。若源码无法定位，先报告可选实施方式，不擅自重写整站或直接修改压缩 bundle。
按主站现有标注 schema 归档两个入口；若不存在，按 Skill 初始化开发环境标注，不在公共业务导航新增文档入口。
本地完成后检查栏目、外链、原有案例及弹窗、桌面与手机表现；部署前保留前一版本，部署后回读两入口和根域名原跳转。域名配置不在本次变更范围。
